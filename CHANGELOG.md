## [1.0.0] — 2026-11-14

First public release.

### Added

- Browse WhatsApp and WhatsApp Business statuses via Storage Access Framework folder access
- Grid UI with pull-to-refresh
- Filter statuses (All / Images / Videos) and sort by date (newest / oldest)
- Full-screen media preview with swipe navigation
- Save statuses to an in-app Saved library
- Export saved media to the device gallery
- Share individual media items through the system share sheet
- Share-app action that links to the latest GitHub APK release
- Light, dark, and system theme modes
- WhatsApp-inspired Material 3 UI (Compose)
